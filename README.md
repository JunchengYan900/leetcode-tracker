# LeetCode Tracker

A full-stack web application to track LeetCode progress.

## Features
- Add problems with difficulty (Easy/Medium/Hard)
- Mark problems as completed
- Delete problems
- View statistics (total, completed, difficulty distribution)

## Tech Stack
- Backend: Flask (Python)
- Database: SQLite
- Frontend: HTML

## How to Run

```bash
python3 -m venv venv
source venv/bin/activate
pip install flask
python3 app.py
